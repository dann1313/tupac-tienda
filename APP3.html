Conectar base de datos

Pega tu configuración de Firebase

Ve a console.firebase.google.com → tu proyecto → ⚙️ Configuración → Tus apps → sección SDK → copia el bloque firebaseConfig

¿No tienes Firebase aún? Ver guía paso a paso →

Paso 1: Entra a console.firebase.google.com con tu Gmail

Paso 2: Clic en "Agregar proyecto" → escribe tupac-tienda → desactiva Analytics → Crear

Paso 3: En el menú izquierdo: Compilación → Realtime Database → Crear base de datos → elige us-central1 → modo prueba → Activar

Paso 4: Arriba a la izquierda: ⚙️ Configuración del proyecto → baja hasta Tus apps → clic </> (web) → registra con cualquier nombre → copia el objeto firebaseConfig

Paso 5: Pégalo arriba y toca Conectar

✓ El plan gratuito aguanta perfectamente: 1 GB de datos, 10 GB de transferencia al mes, 100 conexiones simultáneas.
